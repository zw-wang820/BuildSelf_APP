## 二、模块改动明细

### 1. 待办统计功能（新增）
- **方案决策**（用户拍板）：统计维度 = 分类（工作/生活/阅读/学习）+ 优先级（高/中/低）；未完成口径 = **按截止时间**（`due_date` 落在时间段内且未完成）；近 7 天每日完成趋势。
- **统计口径**：总览区统一"到期口径"（`due_date ∈ 时间段`，含边界日 23:59:59）；趋势图按 `completed_at` 归日；重复待办按实例统计；物理删除不参与。
- **统计页**（`todo_stats_screen.dart`）：
  - 时间段切换：本周 / 本月 / 近 30 天 / 自定义（日期范围选择器）
  - 总览四卡：到期总数 / 已完成 / 未完成 / 完成率
  - 维度 Tab：按分类 / 按优先级，标签行 = emoji + 名称 + 进度条 + 完成数/总数 + 完成率，点击下钻明细
  - 近 7 天完成柱状图（纯 widget 自绘、零依赖、每柱可点击查看当日完成清单）
  - 下钻明细弹层复用 `TodoItemCard`，支持勾选完成/恢复与编辑
- 数据层：`TodoRepository.getStats`（SQL 仅时间过滤，内存聚合）+ `TodoStats` 模型
- 入口：待办列表页 AppBar「📊 统计」按钮，路由 `/todo/stats`

### 2. 左滑删除二次确认（新增）
- 左滑待办滑到底 → 弹确认框（取消卡片弹回，确认才删除），防止误删

### 3. 待办回收站（新增）
- **数据库 v6 迁移**：`todos` 表新增 `deleted_at` + `updated_at` 两列（兼容通用 `softDelete`/`restore`）
- 待办删除改**软删除**：`TodoRepository.delete` 写 `deleted_at`，不再物理删除
- 回收站接入待办：TODO 徽章 + 待办内容 + 分类，支持恢复 / 永久删除 / 清空
- `purgeExpiredTrash` 增加 30 天自动清理 todos
- **所有待办查询排除已删除记录**：`getAll` / `getActiveCount` / `getStats` / `ensureDueInstances` 均加 `deleted_at IS NULL`，回收站待办不影响列表、计数、统计与重复补建
- 文案修正（用户反馈）：二次确认弹窗由「删除后不可恢复」改为「移至回收站 · 可在回收站中恢复」；删除 Toast 改「🗑️ 已移至回收站」

### 4. 首页今日待办排序优化
- 未完成段：全量取回 → 内存排序（**截止日期升序**，无截止排最后 → **优先级高→低**）→ 截取前 8 条
- 修复原 SQL `limit 8` 先截断导致排序不完整的问题（保证展示的是最紧迫的 8 条）
- 已完成段保持完成时间倒序；未完成永远排在已完成之前
