# 2026-09-18 开发日志：生活模块编辑/删除 + 详情页化

## 需求与决策

- 需求：生活 moments 记录增加**编辑功能**，并支持**长按删除**（对齐工作模块交互）。
- 摸底结论：数据层全就绪（`LifeRepository.update/softDelete/restore` 已存在，`LifeRecord` 有 `deletedAt`）；全局回收站本就查询 `lifeRecords` 表，软删后可恢复 30 天。**纯 UI 层改动，零数据库迁移。**
- 第一版把编辑入口放在详情 BottomSheet 底部按钮行，真机体验后用户反馈不佳，**迭代为工作模块同款**：点进记录是详情**页**，编辑入口在 AppBar。

## 经验沉淀

- 详情页 vs BottomSheet：同模块内已有「详情页 + AppBar 操作」惯例（工作模块）时，新增模块直接对齐，不做局部变体（sheet 底部按钮行），避免同 App 内交互形态分裂。
