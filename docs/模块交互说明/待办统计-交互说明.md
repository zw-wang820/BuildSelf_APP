# 待办统计 — 交互说明文档

> 功能：待办完成情况统计（时间段内完成 / 未完成，支持按分类、优先级维度统计）
> 状态：**方案已确认，待实现** ｜ 日期：2026-08-25 ｜ 分支：feature/ui

---

## 一、功能概述

为待办清单提供**时间段维度的完成情况统计**：

- 统计某时间段内**到期**待办的完成 / 未完成情况（到期口径，反映"该清的任务清了多少"）
- 支持按 **分类**（工作 / 生活 / 阅读 / 学习）与 **优先级**（高 / 中 / 低）两个维度查看
- 展示近 7 天**每日完成趋势**柱状图（以完成时间归日）

**范围边界**：仅统计展示，不新增/修改待办数据；不引入图表库；不做数据库迁移。

---

## 二、统计口径（数据定义）

所有时间比较基于本地时区，时间段含边界日（`start 00:00:00` ~ `end 23:59:59`）。

| 指标 | 口径 | 依据字段 |
| --- | --- | --- |
| 到期总数 | `due_date` 落在时间段内（含当天 23:59:59） | `due_date` |
| 已完成 | 到期总数中 `is_completed = 1` | `due_date` + `is_completed` |
| 未完成 | 到期总数中 `is_completed = 0` | `due_date` + `is_completed` |
| 完成率 | 已完成 ÷ 到期总数（无到期数据时为 0） | 计算 |
| 每日完成数 | `completed_at` 落在当日 00:00:00 ~ 23:59:59（近 7 天，含今天） | `completed_at` |

**口径说明**
- 总览区与分类 / 优先级维度统一用**到期口径**（`due_date`），三处数字互相咬合（各标签之和 = 总数）。
- 趋势图用**完成时间**归日，独立展示，不与总览交叉计算。
- **重复待办**：按实例统计（每个到期实例独立计入；实例的 `due_date` 即该期日期）。模板本身（无到期日期或模板日期早于统计区间）不重复计入。
- **已删除待办**：物理删除后不参与统计。

## 三、入口

- **位置**：待办列表页（`TodoListScreen`）AppBar 右侧，新增「📊 统计」按钮（`EmojiIcon`，图标按钮样式与搜索入口一致）。
- 点击后 `Navigator.pushNamed` 进入统计页（新增路由 `todoStats`）。

```
┌─────────────────────────────────┐
│ ‹  待办统计          📊          │  ← AppBar（返回 + 标题）
├─────────────────────────────────┤
│ [本周] [本月] [近30天] [自定义 ▾] │  ← 时间段快捷切换（胶囊样式，同筛选栏）

├─────────────────────────────────┤
│ [按分类] [按优先级]               │  ← 维度 Tab（同列表页筛选样式）
│ 💼 工作  ████████░░  5/8   63%   │  ← 标签行（emoji + 名称 + 进度条 + 完成/总数）
│ 🌿 生活  ████████   3/3  100%   │
│ 📖 阅读  ██░░░░░░   0/1    0%   │
│ 📚 学习  ░░░░░░░░   0/0    —    │
├─────────────────────────────────┤
│ 近 7 天完成趋势                   │
│   ▂▂▄▁▂▅▃  （自绘柱状图）        │  ← 每柱可点击
│  一二三四五六日                   │
└─────────────────────────────────┘
```

### 元素明细

| 元素 | 说明 |
| --- | --- |
| 时间段胶囊 | 本周 / 本月 / 近 30 天 / 自定义；选中高亮场景色（`AppColors.todo`），样式复用列表页筛选栏 |
| 总览四卡 | 复用 `AppCard`，大数字 + 小标签；完成率显示百分比（`到期总数 = 0` 时显示 `—`） |
| 维度 Tab | 「按分类」「按优先级」两个入口，切换后标签行内容重算 |
| 标签行 | 每行：分类 emoji（💼🌿📖📚）或优先级色点（🔴🟡🟢）+ 名称 + 进度条 + `已完成/到期总数` + 完成率；整行可点击下钻 |
| 进度条 | 复用首页 `_buildProgressBar` 同款自绘（6px 圆角填充条），完成率颜色用分类 / 优先级对应色 |
| 趋势图 | 7 根柱，高度按当日完成数归一化；无数据日为占位小柱；柱下方标周几（一二三四五六日）；当前日期柱高亮 |

### 视觉规范

- 场景色：`AppColors.todo`（主）、`AppColors.category` 四色（分类维度）、`AppColors.error/warning/success`（优先级维度）
- 背景 `NexusBackground`、卡片 `AppCard`、图标 `EmojiIcon`，字号走 `AppProvider.textScale`

## 五、交互流程

```
进入统计页（入口：列表页 📊）
  │
  ├─ 默认：时间段 = 本周，维度 = 按分类，加载数据
  │
  ├─ 切换时间段（快捷 / 自定义）→ 全部区域即时重算刷新
  │    自定义：弹「起始日期 + 结束日期」选择器（默认本周一~今天，结束不早于起始）
  │
  ├─ 切换维度 Tab → 标签行列表重算（总览四卡不变，趋势图不变）
  │
  ├─ 点击标签行 → 下钻明细页/弹层：
  │    该标签 + 当前时间段内 到期待办清单（未完成在前，已完成灰字删除线在后）
  │    复用 TodoItemCard，支持勾选完成/恢复、点击编辑，操作后返回时统计刷新
  │
  ├─ 点击趋势柱 → 弹出该日完成待办清单（仅当日 completed_at 的记录）
  │
  └─ 返回列表页 → 无状态残留，下次进入重新加载
```

**加载与刷新**
- 首次进入加载中态（居中菊花，同列表页）
- 切换时间段 / 维度：立即刷新，不做过渡动画；数据为空时显示空态

## 六、状态与反馈

| 状态 | 表现 |
| --- | --- |
| 加载中 | 居中 `CircularProgressIndicator`（场景色） |
| 无数据（时间段内无到期待办） | 空态：📋 emoji + 「该时段没有到期待办」+ 提示文案（复用首页空态组件） |
| 标签行无数据（某分类 0 条） | 仍显示行，进度条空、完成率 `—` |
| 自定义日期非法 | 结束早于起始 → 阻止选择并 Toast「结束日期不能早于开始日期」 |
| 下钻明细为空 | 空态：「该范围没有待办」 |

---

## 七、边界与约束

1. 时间段上界：快捷档（本周/本月/近 30 天）结束日 = 今天；自定义不受限
2. `due_date` 为 null 的待办（未设截止）**不计入**到期统计（不在任何时间段内）
3. 重复待办实例按实例统计，见口径说明
4. 首页"已完成仅保留当天展示"规则**仅影响首页预览，不影响统计**（统计读全量历史）
5. 物理删除的待办不参与统计
6. 趋势图只做近 7 天（含今天），不随自定义时间段变化

## 八、技术实现要点（供实现阶段参考）

- **数据层**：`TodoRepository` 新增统计查询方法，SQL 仅做时间过滤（`due_date` / `completed_at`），聚合在内存完成（单用户数据量小）
  - 方案：一次拉取 `user_id = ? AND due_date BETWEEN ? AND ?`（含已完成、未完成），内存按维度分组统计
  - 趋势数据：一次拉取 `completed_at BETWEEN ? AND ?`（近 7 天），按天归集
- **模型**：新增 `TodoStats`（到期总数 / 已完成 / 未完成 / 完成率 + 各维度分组结果 + 近 7 天趋势数组）
- **页面**：新增 `features/todo/screens/todo_stats_screen.dart`
- **路由**：`routes.dart` 注册 `todoStats`；`app_router.dart` 映射
- **入口**：`todo_list_screen.dart` AppBar 加统计按钮
- **复用**：`AppCard` / `EmojiIcon` / `TodoItemCard` / `NexusBackground` / 空态组件 / Toast
