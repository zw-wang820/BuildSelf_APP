# 工作统计 - 交互说明

> 版本：v0.1（待审核）
> 范围：按时间窗口（周/月/季度/年/自定义）统计工作记录，支持按分类统计
> 前置：工作模块已完成类型体系重构（💡心得/🤔思考/📝日志/📚待学项 + 自定义分类）、待学项完成状态

---

## 一、需求理解

- 按 **周/月/季度/年/自定义时间** 看工作记录的量与分布
- 按 **分类**（4 内置类型 + 自定义分类）统计各类记录占比

---

## 二、页面方案（推荐 A：独立统计页）

### 入口
工作列表页 AppBar 右侧新增「📊」按钮（在 🔍 搜索旁）→ 工作统计页。

### 页面结构

```
┌────────────────────────────────────┐
│ ← 工作统计                        │
│ [本周] [本月] [本季度] [今年] [自定义] │ ← 时间窗口 chips
│ ┌────────────────────────────────┐ │
│ │ 记录总数 12 · 待学完成 3 · 日均 0.8│ │  ← 摘要卡
│ └────────────────────────────────┘ │
│ 分类统计（横向条形图）               │
│ 💡 心得    ████████ 5 (42%)        │
│ 🤔 思考    ████     3 (25%)        │
│ 📝 日志    ███      2 (17%)        │
│ 📚 待学    ██       2 (17%)        │
│ 📌 项目A   ▏        1 ( 8%)        │
│                                    │
│ 各分类明细（点击分类 → 该分类列表）    │
└────────────────────────────────────┘
```

### 交互细节

| 环节 | 行为 |
|---|---|
| 时间窗口 | 预设 chips：**本周**（周一起）/ **本月** / **本季度** / **今年**；「自定义」用日期区间选择器 |
| 摘要卡 | 记录总数 / 待学项已完成数（`doneAt` 落在窗口）/ 日均记录数（总数 ÷ 窗口天数） |
| 分类统计 | 按 `recordType` 分组计数（内置 4 类 + 自定义分类，按数量倒序），**横向条形图**（自绘，长度按最大值归一化）+ 数量 + 占比 |
| 分类明细 | 点击某分类条 → 进入该分类的**记录列表**（复用列表页筛选逻辑，时间段内该分类的记录） |
| 空态 | 时间窗口内无记录：显示空态引导 |

### 待学项完成统计
- 待学项在分类统计里展示「已完成/总数」：`📚 待学 2/5`（窗口内创建的，已完成 X 个）
- 摘要卡的「待学完成」= 窗口内 `doneAt` 落点数量（含早前创建本窗口完成）

---

## 三、数据与实现要点

1. **无迁移**：全部基于 `created_at` / `done_at` / `record_type` 内存统计。
2. **时间段计算**：周（周一起）→ 月 → 季度（1-3/4-6/7-9/10-12 月）→ 年 → 自定义区间。
3. **实现**：新增 `work_stats_screen.dart`；复用列表页的 `WorkRepository.getAll` + 内存过滤；分类条形图自绘（`CustomPaint` 或 Row+FractionallySizedBox，零依赖）；路由 `/work/stats`。
4. **分类列表下钻**：复用 `WorkListScreen`？或统计页内嵌过滤列表。推荐统计页内点击分类条 → 统计页内切换"分类筛选"直接显示该分类记录（单页内完成，不跳转）。

## 四、验证清单（真机）

1. 工作列表 AppBar 📊 → 统计页，默认「本月」
2. 切换本周/本季度/今年/自定义，摘要与分类统计随之变化
3. 记录总数/各分类数量与列表实际一致；占比合计 ≈ 100%
4. 待学项显示「已完成/总数」；摘要待学完成数正确
5. 点分类条 → 下方显示该分类记录列表
6. 空窗口显示空态
