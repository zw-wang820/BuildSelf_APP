# 待办自定义分类 — 交互说明文档

> 功能：新建/编辑待办时可自定义分类（保留内置四类，可新增/重命名/删除自定义分类）
> 状态：**方案待确认** ｜ 日期：2026-08-26 ｜ 分支：feature/ui

---

## 一、功能概述

待办分类从「固定四类」扩展为「**内置四类 + 用户自定义分类**」：

- 一条待办仍只属于**一个分类**（单选，不做多标签）
- 内置：工作 💼 / 生活 🌿 / 阅读 📖 / 学习 📚（保留，不可删除）
- 自定义：用户新建（名称 + emoji），颜色自动分配；支持**重命名**（同步历史待办）与**删除**（该分类待办自动归入"工作"）
- 自定义分类同样参与列表筛选、统计维度、回收站展示

## 二、数据与架构

### 数据库 v7 迁移

```sql
CREATE TABLE IF NOT EXISTS todo_categories (
  id TEXT PRIMARY KEY,          -- uuid
  user_id TEXT NOT NULL,        -- 归属用户
  name TEXT NOT NULL,           -- 分类名（同一用户内唯一）
  emoji TEXT NOT NULL DEFAULT '🏷️',
  color_index INTEGER NOT NULL DEFAULT 0,  -- 色板下标
  created_at TEXT NOT NULL
);
CREATE INDEX idx_todo_categories_user ON todo_categories(user_id);
```

### 分类信息模型

- 新增 `TodoCategoryInfo`：name / emoji / label / color / isCustom / id（自定义才有）
  - 内置四类从 `TodoCategory` 枚举构造（isCustom = false）
  - 自定义从 `todo_categories` 表构造（isCustom = true，color 取色板 `color_index`）
- `Todo.category` 字段存储分类名（内置枚举名 或 自定义名）；展示时经解析器取 emoji/label/color
- 解析器：内置枚举优先匹配，未命中查自定义列表；查不到（分类已删）回退「工作」

### 影响面

| 位置 | 改动 |
| --- | --- |
| 新建/编辑表单 | 分类区显示 内置 + 自定义 + 「＋新建分类」 |
| 待办列表页 | 筛选 tab 动态生成（内置 + 自定义） |
| 待办统计页 | 按分类分组自动包含自定义分类 |
| 待办卡片 | 分类徽章按解析结果显示 emoji/名称/颜色 |
| 回收站 | 待办条目 subtitle 分类名解析 |
| 首页 | 待办行不显示分类，无改动 |

## 三、交互流程

### 1. 新建 / 编辑待办 → 分类选择

```
[新建待办] 表单 · 分类标签区：
  [💼 工作] [🌿 生活] [📖 阅读] [📚 学习] [🏃 健身] [＋ 新建分类]
   ↑ 内置四类固定    ↑ 用户自定义（按创建时间序）    ↑ 新建入口
```
- 选中态：分类色浅底 + 边框高亮（沿用现有 chip 样式）
- 编辑待办时：若该待办分类是自定义且仍存在，正常选中显示；若已被删除，自动回退选中「工作」

### 2. 新建分类

```
点击「＋ 新建分类」→ 弹出底部表单：
  ┌─────────────────────────┐
  │ 新建分类                  │
  │ 分类名称 [____]  （必填，≤ 6 字）│
  │ 选择图标：[💼 🌿 📖 📚 🏃 💪 📌 ⭐ …]（12 个常用 emoji）│
  │ 颜色：自动分配（8 色板循环取下一个未用色）│
  │         [创建]           │
  └─────────────────────────┘
```
- 名称与现有分类（内置 + 自定义）重名 → 阻止并 Toast「该分类已存在」
- 创建成功后：新分类出现在分类区并**自动选中**

### 3. 分类管理（入口：待办列表页 AppBar「🏷️」）

```
分类管理页：
  ┌─────────────────────────┐
  │ 内置分类（不可编辑）        │
  │ 💼 工作   🌿 生活  📖 阅读  📚 学习 │
  │                          │
  │ 我的分类                  │
  │ 🏃 健身    [✏️] [🗑️]      │
  │ ⭐ 重要    [✏️] [🗑️]      │
  │ [＋ 新建分类]             │
  └─────────────────────────┘
```
- **重命名**：弹输入框（预填原名），确认后更新该分类名 + **批量更新**其下待办的 `category`，Toast「已重命名」
- **删除**：弹确认框「将删除分类「健身」，其中 N 条待办将归入「工作」」，确认后删除分类 + 批量更新待办为 work
- 内置分类不可删除/重命名

## 四、边界与约束

1. 分类名：必填、≤ 6 字、同一用户内唯一（内置名也不能重复用）
2. 删除分类回退「工作」为 V1 策略（保证无数据悬挂）
3. 自定义分类的待办在统计/筛选中按分类名归组；重命名后历史数据随名更新
4. 色板 8 色循环分配，新建时取「当前使用色之外」的下一个，避免与内置色冲突（允许重复则优先新色）
5. 首页今日待办不展示分类徽章，不受影响
6. 删除自定义分类不影响其历史统计（数据归入工作后按工作统计）

## 五、技术实现要点

- **v7 迁移**：`todo_categories` 表 + 索引（`_onUpgrade`，`oldVersion < 7`）
- **模型**：`TodoCategoryInfo` + 解析器；`Todo.category` 保持 String 语义（现有枚举 name 兼容），新增 `categoryInfo` getter（需携带自定义分类列表，或在 Repository 层解析后组装）
- **Repository**：`getCustomCategories` / `addCustomCategory`（重名校验）/ `renameCustomCategory`（含批量更新待办）/ `deleteCustomCategory`（含批量回退 work）
- **表单**：`add_todo_sheet.dart` 分类区改造 + 新建分类底部表单（名称 + emoji 选择器）
- **列表**：`todo_list_screen.dart` 筛选 tab 动态化（加载自定义分类后生成），`_TodoFilter.category` 从枚举改为分类名字符串
- **统计**：`todo_stats_screen.dart` 分组按名称，解析展示
- **回收站**：subtitle 分类名解析（自定义分类需查询）
- **新增页面**：分类管理页（`category_manage_screen.dart`，路由 `/todo/categories`）
- 色板：新增 8 色常量数组（可复用书封色板）
