# 目标管理统计 - 交互说明

> 版本：v0.1（待审核）
> 范围：按**时间段**统计目标的**完成情况**与**未完成情况**
> 前置：目标管理已上线（新建/编辑/进度/完成/放弃/删除、成就墙）

---

## 一、需求理解

用户想按**时间段**（如本周/本月/自定义区间）看目标管理成果：
- **完成情况**：这段时间完成了多少目标、达成率如何
- **未完成情况**：没完成的怎么分布——还在做、已放弃、还是逾期了

数据完全支撑：`Goal` 模型已有 `startDate`（创建/启动时间）、`completedAt`（完成时间）、`targetDate`（截止时间）、`status`（进行中/已完成/已放弃）。

---

## 二、统计口径（推荐）

以**时间段内创建（启动）的目标**为统计对象（`startDate` 落在所选区间），这样"完成/未完成"是同一批目标的当前状态，口径统一、达成率可算：

| 维度 | 定义 |
|---|---|
| 总目标 N | 时间段内创建且未删除的目标数 |
| **已完成 X** | 其中 `status = completed`（达成率 = X/N） |
| **未完成 N-X** | 其中细分：**进行中**（active）、**已放弃**（abandoned）、**逾期未完成**（active 且 `targetDate < 今天`） |
| 附注 | 时间段内**共完成** M 个（`completedAt` 落在区间，含早前创建、此段完成的目标）——即"这段时间完成的成果量" |

> 一个时间段的"成果" = M（完成时刻口径）+ 启动目标达成率（创建批次口径），两个数字互补展示。

## 三、页面方案（推荐 A：独立统计页）

### 入口
目标看板页 AppBar 右侧新增「📊」按钮（在 🏆 成就墙旁）→ 目标统计页。

### 页面结构

```
┌────────────────────────────────────┐
│ ← 目标统计                        │
│ [本周] [本月] [近90天] [自定义]     │  ← 时间段选择 chips
│ ┌────────────────────────────────┐ │
│ │ 启动目标 8   ✅ 完成 5 (63%)    │ │  ← 摘要卡
│ │ 未完成 3：▶进行中1 ⏸放弃1 ⚠️逾期1│ │
│ │ 附：本段共完成 6 个目标          │ │
│ └────────────────────────────────┘ │
│ 完成情况  [已完成] [进行中] [已放弃]  │  ← 状态 Tab
│ ┌────────────────────────────────┐ │
│ │ 🎯 目标标题        ✅ 2/5 进度   │ │
│ │ 🎯 目标标题        ✅ 已达成    │ │
│ │   （点击 → 目标详情页）          │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

### 交互细节

| 环节 | 行为 |
|---|---|
| 时间段 | 预设 chips：**本周**（周一起）/ **本月** / **近 90 天**；「自定义」用 `showDateRangePicker` 选起止日期 |
| 摘要 | 总启动数 / 已完成数+达成率（环形或进度条）/ 未完成数（细分进行中·放弃·逾期 三个小标签）/ 附注「本段共完成 M 个」 |
| 列表 | 按状态 Tab 切换：已完成（完成时间倒序）/ 进行中 / 已放弃；每行显示标题 + 状态/进度；点击进目标详情 |
| 空态 | 时间段内无目标：显示「该时间段没有启动的目标」，提示切换时间段 |
| 达成率 | 已完成 / 总启动数；无目标时为 0 |

### 备选对比

| 方案 | 形态 | 优点 | 缺点 |
|---|---|---|---|
| **A 独立统计页**（推荐） | AppBar 📊 → 新页 | 空间足、口径清晰、可扩展 | 多一层页面 |
| B 看板页顶部扩展 | 现有统计概览区增强 | 零跳转 | 空间受限，时间段筛选+分组列表放不下 |
| C 弹层 | 底部弹出 | 轻量 | 列表/筛选在弹层内体验差 |

## 四、数据与实现要点

1. **无迁移**：全部字段已存在（startDate/completedAt/targetDate/status/deletedAt）。
2. **新增方法**（goal_repository）：`getAllGoals(userId)`（全量未删目标，统计页内存过滤；现仅有 getActive/getCompleted，缺 abandoned 全量）。
3. **统计逻辑**：`startDate ∈ [start, end]` 过滤 → 分组计数 + 达成率；`completedAt ∈ [start, end]` 统计"本段完成数"。
4. **UI 复用**：时间段 chips 样式对齐习惯页筛选；达成率进度条/环形对齐统计卡风格；目标行复用 `GoalItemCard` 或简版行。
5. **改动文件**：新增 `goal/screens/goal_stats_screen.dart`；`goal_board_screen.dart` AppBar 📊 入口；`goal_repository.dart` 加 `getAllGoals`；`routes.dart`/`app_router.dart` 注册 `/goal/stats`。

## 五、验证清单（真机）

1. 看板页 AppBar 📊 → 统计页，默认「本月」
2. 切换本周/近 90 天/自定义，摘要与列表随时间段变化
3. 摘要数值与实际目标一致：启动数 = 已完成+进行中+已放弃；达成率正确
4. 未完成细分（进行中/放弃/逾期）与目标实际状态一致
5. 状态 Tab 切换列表正确；点击目标进详情
6. 空时间段显示空态
7. 返回看板页正常
